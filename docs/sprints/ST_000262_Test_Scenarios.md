# ST-000262 Test Scenarios

Scope: Windows UTF-8 version notice; PR 268. No full installation is needed for the defect fixture. Copy only the notice script, write a release receipt and sample entrypoint, and mock the release lookup. Fixtures use temporary directories and do not modify a shared project or receipt.

## Acceptance Scenarios

| AC | Scenario | Expected result |
|---|---|---|
| 1 | Ordinary Windows Python, no PYTHONUTF8 or interpreter UTF-8 flag, AGENTS.md containing U+201D, mocked v0.1.53 with v0.1.52 installed | UTF-8 mode is 0; notice names both versions and sync devkit |
| 2 | CLAUDE.md and AGENTS.md separately and together; ASCII control; U+201D in entrypoints and receipt | Explicit UTF-8 reads; expected notice and one mocked lookup |
| 2 | Current release or empty tags; missing receipt/entrypoint; invalid JSON, absent source fields, local-source receipt, entrypoint without source; release lookup failure | Empty notice; missing/local inputs do not perform lookup |
| 3 | Run identical entrypoint, receipt and ordinary Windows regression tests against exact base and fixed script revisions | Base fails because notice is empty; fixed revision passes; record revision, source/test hashes, commands and results |
| 4 | Build isolated distribution and test its installed notice asset; inspect deployment metadata and changelog; run builder check, validators, internal harness suite and complete deployment aggregate | Generated bytes match owner; providers/profiles preserved; all checks pass; no manual version bump |
